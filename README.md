One two-part micro-confession, exactly as it was typed and never sent: a To: line naming who it was meant for, and the unsent message itself. The confession is about a broken mug, a replacement bought in secret, and the small guilt that never got confessed — the reason it stayed in drafts is felt in the cover-up, not stated.

The confession, in full:

> To: Leo, my old roommate
> I never told you I broke your favourite mug; I bought an identical one and let you think you'd misremembered it.

## Run it

```sh
python3 main.py
```

`main.py` writes the confession to `/output/entry.txt` (137 characters, two lines, no trailing newline) and prints it. It self-checks the gate first: 1–260 characters, exactly two lines, a To: line naming someone, and a message of 1–200 characters. The run is fully deterministic — no input, no randomness, no network, no clock.
